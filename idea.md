**Final idea: AI-generated persona simulator for live product UX testing**

A tool where teams give a **product/app** and a **high-level goal**, then AI automatically defines realistic user personas, tests the live product as those users, and generates UX reports.

Flow:

**Product + goal → AI creates personas → AI users operate live app → records journeys → generates insights**

Example:

> Goal: test onboarding for a payments app
> AI creates personas like:
>
> * non-technical small-business owner
> * skeptical first-time founder
> * busy finance manager
> * price-sensitive freelancer

Each persona then uses the product differently, revealing different UX issues.

Core output:

* Auto-generated user personas
* Screen recordings of each journey
* Click paths and hesitation points
* Confusion, backtracking, drop-offs
* Task completion/failure
* Persona-specific UX feedback
* Prioritized recommendations

One-line pitch:

**AI creates realistic users, lets them use your product, and reports where each type of user gets confused, stuck, or drops off.**
